Sizzle & Serve — a tiny original cooking game. One 3-minute shift: tickets arrive on the order board, you grab ingredients, grill, fry, chop and bake them on their stations, assemble each dish on the plate, and serve it before the customer's patience runs out. Burnt food goes in the bin, a wrong dish gets sent back, and three strikes close the kitchen. Reach 120 coins to win the shift. Mouse and keyboard, no build step, no network — just open `game/index.html` in a desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play. `main.ts` hands the game in: `MAKEFUN_OUTPUT_DIR=out node main.ts` copies `game/` and `screenshots/` to `out/` and writes `out/dossier.json`.
